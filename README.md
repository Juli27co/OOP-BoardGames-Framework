# TwoPlayerBoardGameFramework

A C# .NET console application implementing an extensible object-oriented framework for multiple two-player board games.

## Features
- Supports multiple games (Tic-Tac-Toe, Gomoku, Connect Four, etc.)
- Human vs Human and Human vs Computer modes
- Undo/redo functionality
- Save/load game state (.txt and .json)

## Run
```bash
dotnet clean
dotnet run
